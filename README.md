# 🎸 YARG Song Browser

A web application for browsing, searching, and exploring your **YARG** song library.

Originally created to make it easier to navigate large YARG collections, this project provides a fast, responsive interface for finding songs, viewing song information, and discovering music through a random song generator.

---

## ✨ Features

- 🔍 Instant song search
- 🎸 Browse your complete YARG library
- ↕️ Sort by Artist, Song, Album, and Year
- ▲▼ Ascending and descending sorting
- 🎲 Random Song generator
- 🎵 Detailed song information
- 📊 Live statistics
  - Total Songs
  - Artists
  - Albums
  - Genres
- 📱 Responsive layout
- 🌙 Modern dark theme inspired by YARG
- 🔤 Automatically sorted by Artist and Song when loaded

## 🚀 Running Locally

1. Clone or download this repository.
2. Export your `songs.json` from YARG.
3. Copy the file into:

```
data/songs.json
```

4. Open the project in Visual Studio Code.
5. Launch the site using **Live Server**.

---

## 🔄 Updating Your Song Library

Whenever you download new songs in YARG:

1. Export a fresh `songs.json`.
2. Replace:

```
data/songs.json
```

3. Open the project in VS Code.
4. Stage the updated file (if needed).
5. Commit using a message such as:

```
Update song library
```

6. Push the commit to GitHub.
7. GitHub Pages automatically updates the website after a few minutes.
